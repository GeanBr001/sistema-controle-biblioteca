# Banco de dados

Os scripts desta pasta pertencem ao modelo atual de biblioteca. O modelo legado de comércio eletrônico foi removido deste diretório e permanece somente no backup anterior à limpeza.

Antes de alterar o banco de produção, exporte um backup do Supabase. As tabelas utilizadas pelo backend atual são `users`, `categories`, `books`, `loans` e `stock_movements`, além da view `dashboard_summary`.
